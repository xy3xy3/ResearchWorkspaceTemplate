# 架构与边界

工作区保存研究意图、约束、证据、任务和报告；独立代码仓库保存实现、依赖锁和实验；独立论文仓库保存 LaTeX 与自制图表。工作区注册本机路径但不提交绝对机器配置。参考实现放忽略的 refrepo/，只从记录的 URL 重建。

## 一个事实只有一个权威来源

brief 是目标，spec 是约束，task/meta.json 是任务状态和事件，research 是研究证据，.runtime 是原始运行和临时材料。报告不是证明实验发生的替代品。已归档任务不改写；后续工作创建关联任务。资料 paper.md 是解析原文，notes.md 才是笔记。

## 原生编排

唯一模型编排者是当前 Codex 主 Agent。它使用原生角色、实际工具与权限，把独立问题分给通常 1–3 个子智能体，再整合原始证据。子智能体不派生子智能体，不另启 Codex。缺原生能力时明确顺序处理或审查缺口，不用 Python/CLI 桥伪装。

checkpoint.py 仅保存 N- 状态，记录冻结的 brief/spec、原预算、已发生的证据事件与下一步。检查是协作式的，不抢占模型调用；墙钟预算包含空闲时间，恢复不重置。事件里的 agent_id/model 是主 Agent 报告值，不是身份认证。旧 loop.py 不再运行，旧 C- 状态仅供人工读取后续接，不静默迁移。

脚本可运行文献 HTTP 请求、本地解析、Git 克隆、实验、编译、绘图与状态检查，但不得启动模型进程。它们不是跨机器调度器或会话关闭后的守护进程。

## 自包含与渐进加载

专业技能按需加载，scripts/references/assets 随技能分发；不依赖另一个工作区的 tools 或 hooks。首版五份 runtime.py 保持一致，既有测试继续约束一致性。文献服务共用同技能的 service_client.py；论文预处理用本技能 paper_io.py；LaTeX/绘图各随包提供相同的小型 paper_repo.py。没有隐藏的全局安装路径。

## 论文资料与论文成品分开

预处理优先导入已有 MinerU/PaddleOCR Markdown；显式本地解析时仅把自己的临时 PDF/图片放 .runtime，发布文本、哈希与来源。缺失视觉证据保持缺失。不会删除用户原文件或自动上传 PDF。资料 ref/ 的二进制忽略规则不适用于独立论文仓库的自制图表。

参考克隆要求目的地被外层 Git 忽略，不覆盖已有仓库，不运行克隆后的脚本，跳过 LFS/submodule。克隆时间/环境限制不是恶意代码 OS 沙箱，用户自定义 Git 过滤器仍属于本机信任边界。

## 实验与写作

既有实验运行器保留固定 commit、种子、数据/划分、指标与对照组记录，拒绝无效指标和实验中代码漂移；confirmatory 禁止脏代码。配对分析区间描述种子变化，不自动代表显著性或数据总体不确定性。收据不包含重现所需的全部依赖/数据/原始字节。

写作从证据映射到论点，而不是用漂亮文字补造证据。编译检查和图表哈希只是工具检查；原文支持、科学解释和视觉排版仍需相应审查。角色模型分层是配置选择，不是模型能力或审稿准确率的实测证明。

## 权限

Codex 的审批和沙箱设置仍生效；工作区配置不自动授予外层相邻仓库的写权限。外部搜索披露查询内容，私有资料外传必须授权。真实密钥仅由声明式环境加载器读取，不在 argv、日志或 Git 中公开。解析器、Git、实验和 TeX 在本机用户权限内运行；不可信输入/代码应另有 OS 隔离。
