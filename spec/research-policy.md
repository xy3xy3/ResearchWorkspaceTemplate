# 研究约束

本文件由人类维护。Agent 可以提出修改建议，但不为获得正结果自行修改约束。

计算仅限登记的本地机器；不使用 SSH、云 GPU 或第三方提交服务。代码依赖和数据获取遵守独立代码仓库的说明；新安装、付费 API、下载大型/受限数据需要明确授权。密钥只由执行工具加载。

`autonomy.json` 的 total/round/experiment 都是墙钟秒。experiment 是一份计划所有 seeds 的累计上限，而非每个 seed；loop 将子实验时间计入整个轮次和周期。单独手工多次调用实验脚本不会共享 cycle 累计预算，需由调用者控制。预算不是 GPU 显存/费用配额。时间到后停止进程组，清理可能需要短暂额外时间。

默认低成本先行：查明已有证据 → 最小可区分实验 → 扩展验证。不得伪造引用、实验、审查或统计显著性。未找到相关工作不等于不存在；文献元数据检索不等于全文核验。避免测试集调参，保留失败和反例，报告真实的数据划分和完整配置。

约定需要针对课题补全的内容：可用数据及许可、硬件/设备数、允许的依赖与联网服务、总费用上限、主指标与对照、不可改动的评估协议、结束条件。尚未确认的内容记录在 brief 的缺口中，不默认为已授权。
