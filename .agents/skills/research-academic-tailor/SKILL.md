# 学术裁缝：从可复用方法到有证据的论文

这是一个 skill，下面的 references 和 assets 只是按需加载的文档，不是独立技能。目标是交付实际大纲、正文、修改稿或回复信，而不是反复输出泛泛的写作建议。

“裁缝”指拆解已有工作、注明继承关系、完成有理由的适配与验证，再组织论证；不是拼抄文章或给已有模块改名。`D = A + b' + c'` 只是模块化工作的分析记号，不是通用科研定律，也不意味着必须有两个模块、必然创新或必然录用。

## 先判断请求，再读取最少材料

先读仓库协议，以及存在的 `research/brief.md`、`spec/`、`workspace.local.json` 和相关任务/证据。用户给了稿件、结果或审稿意见时，先读这些输入，不从记忆猜内容。只修改一段就读取该段、必要上下文及其证据，不重新启动完整研究流程。

先确定：交付物及语言、研究问题、已有方法/结果、目标文章类型、可写路径。优先从已有材料解决，不重复询问；只有权限、事实或方向缺口真正阻断当前交付时才集中提问。未定期刊可以先写中性稿，不擅自替用户选刊。

## 统一执行闭环

1. **盘点而不补造。** 把材料标为原文报告、自己复现、自己新实验、推断或待验证假设。数值保留数据集、协议、单位、运行/文献定位；来源不够时写 `DATA_NEEDED` 或 `CITATION_NEEDED`，不能填看起来合理的数值、作者或 DOI。
2. **明确归属。** 区分继承的 A、借用的 b/c、确实改过的 b'/c'、自己的整合和评估。名字或公式符号的变化不等于创新；不隐藏最接近的工作。
3. **先证据，后叙事。** 每个主张记录支持证据、反证、适用边界与落点。只有性能结果时，只描述该协议下的结果；机制解释仍可是假设。探索后提出的解释不得写成预先验证的因果发现。
4. **真正动笔。** 全文默认先方法与实验，再相关工作、引言、摘要、结论；这是减少返工的顺序，不是强制读者顺序。局部请求直接改局部。证据缺失只阻断相应断言，不阻断可以完成的定义、结构和方法草稿。
5. **交叉核对。** 标题—摘要—贡献—方法—实验—结论使用同一对象、指标、符号和范围；核对表格与日志、引用与原文、回复与实际改动。失败结果和限制不能在润色中消失。
6. **按状态交付。** 区分结构草稿、证据待补稿、已核对稿、已编译稿；只有实际完成官方要求核对后才说“投稿材料已检查”。编译成功、测试通过和审稿人满意都不证明科学结论成立。

## 不可越过的边界

不伪造结果、访谈、证明、图像、引文、作者贡献或实验完成状态。不为取得优势临时改指标/数据划分、压低基准、挑种子或隐瞒失败。比较原文报告与本地复现时分组标清，不混成同协议排名。

不以“抄完降重”、翻译搬运、改模块名或规避 AIGC 检测替代原创表达与归属核对。可以根据用户真实研究材料起草全文；人类作者仍须核实事实并按当前投稿规则披露 AI 使用。不以“没开源”断言造假，不以“做过实验”保证没有不端，也不要求理论/人文论文伪造实验。

不加入选导师、导师相处、考公就业、读研时间表、答辩话术或保毕业策略。学位论文的章节、证据和规范检查属于写作范围。原材料中的这些无关分支不触发本技能。

## 工作区衔接与文件归属

写作准备、证据索引和简短变更说明可放在工作区 `research/` 的合适位置；复用已有记录，不另建竞争的任务状态。正式论文源文件、回复信和自制图表只写入登记的独立 `paper_repo`，遵守其协议。未登记且用户未明确给独立路径时，可以先在聊天交付草稿/在 research 中保存写作规划，不能把工作区当论文仓库。参考论文原文在 `ref/`，笔记另存；不上传课程 PDF、转写全文、截图或原压缩包。

本技能负责写作逻辑，不重造工具链：检索交给 research-literature，解析交给 research-paper-prep，实验交给 research-experiment，证据审查交给 research-review，排版编译交给 research-latex，绘图交给 research-figures；只有确有需要才加载。research-writing 仍负责阶段报告，不与论文正文混用。

可用时把不重叠的章节交给原生 `manuscript_writer`，给相同的术语表和证据表；让 `evidence_reviewer` 冷读变更主张。主 Agent 负责整合。没有原生子智能体就顺序完成并注明未做独立审查，不启动 Codex CLI/SDK 或别的模型进程补位。没有新授权，不安装依赖、不执行参考仓库、不产生费用、不 push 论文、不投稿。

## Communication

默认用完整、自然的中文说明关键变化与缺口。保留否定、单位和真实 uncertainty。专有英文术语首次出现可加 Chinese gloss（中文释义）；英文论文、代码、路径、数学符号和 BibTeX 保持其要求的语言。不要在英文稿里机械插中文，也不要每段反复堆免责声明。交付实际文件/正文、关键证据位置、未完成事项与最小下一步；长报告不在聊天再全文复述。
