原 PDF、截图、转写全文和压缩包不进入仓库；清单只记录文件名、页数与哈希。原课程权利不因上传或上游 MIT 许可而转移。这里只发布重新组织的方法说明、短标识和原创模板，不发布课程替代副本。

## 明确的保留、重写与排除

| 原材料中的思路或风险 | 处理 | 最终执行规则 |
|---|---|---|
| 基准 + 可复用部件 | 保留并限界 | 明确归属、接口和任务条件，不声称普遍公式 |
| 分层阅读与数据流拆解 | 保留并补全 | 初筛可略读，做结论/实现须核验方法、实验、最近工作 |
| 先方法与实验再写叙事 | 保留 | 叙事服从真实事实，局部请求不跑完整流程 |
| 模块略改、改符号即可称创新 | 重写 | 区分借用、适配、重实现与实质贡献 |
| 结果提高就证明故事/机制/创新 | 重写 | 性能、机制、因果、泛化和新颖性分别举证 |
| 挑较低基准、调指标、只展示赢的案例 | 排除 | 同协议比较、记录失败、透明选样与模型选择 |
| 必须赢 SOTA、消融每步涨、固定创新数量 | 排除 | 报告观察与边界，负结果可写，不承诺录用 |
| 不开源就是造假、做实验就绝无不端 | 排除 | 不作这类推断；查证来源、过程、数据和归属 |
| 多处抄写后降重、规避 AIGC/抄袭检测 | 排除 | 自己组织表达、正确引用、作者复核与真实披露 |
| 固定模块数/页数字数等于学位达标 | 排除 | 研究问题—章节—证据映射，另核对实际要求 |
| 固定分区费用、OA/EI 录用保证 | 排除 | 当前官方来源、体系/年度与日期分开核查 |
| 讨好审稿人、无关引用、未做却称已完成 | 重写 | 礼貌逐项回应，真实修改，有据不同意 |
| 学位返修不被检查就不改 | 排除 | 逐条核对实质意见与实际修改 |
| 改通信邮箱、隐瞒作者、并行多投等技巧 | 排除 | 作者批准、准确声明、遵守目标实际政策 |

ASR 归一仅用于语境明确的术语，如“学术财富/台风”对应“学术裁缝”，“骁龙实验”对应“消融实验”。不把模糊发音推定为真实模型名称；优先课件、论文原文或代码核对。
