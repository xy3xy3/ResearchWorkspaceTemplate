# 图表与表达：每张图有一个论证任务

图表为论文主张服务。课程 3.2–3.4 与上游指南强调方法图、结果图和整体呈现；本技能不把“固定三张图”当所有期刊的必备要求。

## 先列图表任务，再选工具

每张图填写：要回答的问题、关联 claim ID、来源数据/实现、读者应看到的关系、不能据此推出的结论、拟放章节。概念示意、真实输出和测量图分开标注；图注不能把示意图写成实验验证。

| 类型 | 应表达的核心信息 | 必须核对 |
|---|---|---|
| 方法总图 | 输入、数据流、部件依赖、输出、训练/推理边界 | 与代码及公式一致，继承/新增标清 |
| 主结果表/图 | 指定协议下的性能、成本或权衡 | 单位、方向、比较组、聚合、来源 |
| 消融表/图 | 单模块、组合与控制条件 | 勾选含义明确，不能藏重要配置差异 |
| 诊断/案例图 | 机制线索、边界或代表性失败 | 选择规则、真实样本、版本、限制 |
| 摘要图 | 简洁呈现问题—方法—发现 | 目标是否要求，不装饰性堆模块 |

## 方法图的落地要求

沿输入到输出绘制，标清每个框的语义、主要张量/对象关系、模块插入位置和必要反馈。训练专用信号、冻结组件和推理路径分清。自制图用统一术语，尽量少交叉连线；不要为了视觉简洁隐藏决定方法含义的依赖。借鉴别人布局不等于拥有其图片版权，不直接搬用原图。

交给 research-figures 时传入结构定义、代码定位和图的论证目标，保存可编辑源文件与来源记录。生成图像或漂亮草图不能替代结构核对。

## 数据图与表的落地要求

使用可追溯数据和可重复绘图脚本，注明指标方向、坐标单位、样本量、聚合与误差条含义；缺重复运行时不要编误差条。截断轴、对数轴、归一化和缺失值须清楚解释。只在同协议的可比组中标最佳，不用视觉比例误导读者。

对比表列清额外数据、模型规模或预算差异；消融表用独立列区分组件、位置、输入和训练设置，避免一个勾承担多种含义。表下注明 original reported / reproduced 等来源类型。

图注按“是什么—怎么得到—怎么看—必要条件/限制”写。只读图和图注应能明白比较什么，不必猜缩写。图注不必把讨论全塞进去；复杂解释回正文，关键条件不能省。

## 终稿检查

实际渲染论文后在最终尺寸检查字体、线型/颜色区分、灰度可读性、轴标、表格溢出、图例、清晰度、编号和正文引用。颜色不是唯一编码。改一处术语或结果后同步图、表、摘要和正文。实图保存在独立 paper_repo；原始课件截图和课程素材不随技能发布。
