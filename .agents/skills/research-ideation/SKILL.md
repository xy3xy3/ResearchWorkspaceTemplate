# 问题、假设与判别实验

使用本 skill 的 `references/hypothesis-template.md`，输出 research/questions/、research/ideas/ 的可追踪记录。
输入是人类方向和已有证据，不假设已经存在创新点或正面结果。

先明确当前真正要解释/改进的现象，再提出少量可区分的机制假设；不要为了数量生成几十个同义 idea。
每个候选都必须说明最近邻工作、反证条件、替代解释、实现依赖、数据可得性和本地计算预算。
优先能以小实验区分假设的方案，不将“更复杂”或“调用更强模型”直接包装成创新。
选题可迭代，但改指标、基线或数据划分必须先写 decision，不能在看到结果后悄悄修改规则。

实验设计固定主指标、方向、单位、样本/种子、数据版本、基线、消融和比较预算。
smoke 只验证代码能跑；pilot 决定是否扩大投入；confirmatory 才承担预先约定的主要验证。
如果本地条件不适合，记录缺口并选择可行替代验证，不自动改用云 GPU 或伪造结果。

将计划交给 research-experiment。需要质疑时交给独立 research-review；不要先让审查者接受你的结论。
完成条件是一个能被实验推翻的方案和下一步，而不是漂亮的正面故事。
